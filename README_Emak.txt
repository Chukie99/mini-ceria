MINI CERIA - Hijaiyah • Alfabet • Hewan
APK Edukasi Anak 1-5 Tahun | 100% Offline | Bebas Iklan
by Hermes AI untuk SOPIAN

CARA INSTALL DI HP/TAB ANDROID:
1. Copy file MiniGame_APK_Komplit.zip ke HP/Tab emak
2. Extract, buka index.html di Chrome (bisa langsung main, tanpa install)
   ATAU build jadi APK: upload ZIP ke https://www.pwabuilder.com -> Android -> Download APK (gratis, tanpa Android Studio)
3. Install APK di Tab -> buka app Mini Ceria

CARA MAIN (Emak pegang Tab dulu):
- Pilih kategori: Hijaiyah / Alfabet / Hewan
- Kasih ke anak, volume HP nyalakan
- Suara otomatis: "Yang mana huruf Ba?" -> anak TAP gambar -> feedback suara
  - Benar: "Yeay kamu benar!" + bintang terbang
  - Salah: "Ups itu Ta, coba lagi ya mana Ba?" (nyebutin nama biar belajar)
- Tap 🔊 Ulang kalau anak gak denger
- Tiap 3 benar dapet stiker di Album (atas)

TOMBOL EMAK:
- Tap logo "Mini Ceria" 5x cepat -> masuk Menu Emak (biar anak gak kepencet keluar)
- Kembali ke Menu: tombol <- Menu

FILE PENTING:
- content/hijaiyah.json -> edit soal tanpa ngoding (tinggal ganti prompt_text / correct)
- assets/audio/*.mp3 -> semua suara GadisNeural (id-ID), 15KB/file
- assets/img/*.png -> kartu 600x600, bisa ganti gambar sendiri

TAMBAH GAME BARU (15 menit):
1. Duplikat content/hijaiyah.json -> content/warna.json
2. Ganti isinya, tambah gambar di assets/img, generate mp3 via edge-tts
3. Tambah 1 tombol kategori di index.html -> jadi produk baru Lynk.id!

UKURAN: 686KB total (audio 508KB + img 140KB) -> APK jadi 5-8MB
